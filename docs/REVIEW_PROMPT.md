# レビュー担当チャットに渡すプロンプト

あなたはこのプロジェクトの独立したレビュー担当です。docs/SPEC.mdを正本として読み、開発担当の説明ではなく実際のコード・表示・テストから確認してください。

今回はローカル操作試作のレビューです。コードは編集しないでください。仕様の変更、ファイル削除、依存追加、公開、他チャットへのメッセージ送信は行わないでください。

次を重点的に確認してください。

1. 目標3件・タスク3件の上限と、達成済み目標の枠の扱い。
2. 完了タスクの編集ロック、継続時の解除、再開時の状態維持。
3. 全件完了確認をキャンセルしたときの挙動と、確認の繰り返し表示。
4. 目標0件・タスク0件・1/3・2/3・3/3の進捗。
5. 最新3回の履歴保持、同日の上書き、保存失敗時の整合性。
6. 現在の編集・削除が履歴を変更しないこと。
7. 達成済み目標の振り返り前の削除防止。
8. 入職年月の業界歴計算、年月またぎ、履歴実施日時点の計算。
9. 閲覧モードの変更処理拒否。本番の共有・権限と試作モードを混同していないこと。
10. 保存状態、期限切れ表示、確認ダイアログ、キーボード操作、画面の重なり。
11. 既存の発表資料への意図しない変更がないこと。

追加仕様を好みで要求せず、具体的な不具合・仕様違反・実装段階の誤表示を報告してください。各指摘には重要度、ファイルと行、再現操作、期待動作、実際の動作を付けてください。問題がなければ検証した範囲と未検証の範囲を明示してください。
