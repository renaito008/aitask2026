# 表示・操作確認手順

すべて架空のサンプルで確認してください。保存は現在のブラウザだけに作用します。

1. `start.cmd`を実行し、`http://127.0.0.1:4173`を開く。
2. 「架空のサンプルを読み込む」→確認→「変更を保存」。再読み込みして復元されること。
3. 目標を合計3つ追加。4つ目が追加できないこと。各目標のタスクも3つまで。
4. タスクを完了し、編集・削除・完了解除がロックされること。
5. 全完了時の確認をEscで閉じる。目標が取り組み中に残り、完了タスクのロックも残ること。
6. 「達成を確認」→「まだ取り組む」。完了状態は残り、編集・完了解除が可能になること。
7. 再度達成確認を承認。達成済み欄へ移り、取り組み中の枠が空くこと。
8. 達成済み目標を再開。取り組み中が既に3つなら拒否されること。
9. 未保存状態で「今回の1on1を記録」。保存を促され、履歴が増えないこと。
10. 保存して履歴を記録。同実施日の再記録は確認して上書きすること。
11. 今日以前の異なる実施日を4つ記録。最新3回が残り、現在編集が過去へ反映されないこと。
12. 達成日より後の実施日の1on1に記録すると、達成済み目標が削除可能になること（初期案）。同日記録では不可。
13. 上司の閲覧デモを開く。基本情報が読み取り専用で編集・保存・記録・再開・削除操作がないこと。
14. 別タブで保存し、古いタブの保存が競合で拒否されること。最新情報に更新で復旧すること。
15. キーボードTab/Enter/Escで操作。ダイアログ内のフォーカスと閉じた後の戻りを確認。
16. 1280×720、1920×1080、狭い画面で文字の重なり・横の見切れがないこと。

自動テストは `node --test tests/domain.test.mjs`。容量不足などの保存失敗と破損データはRepositoryの模擬ストレージで検証します。
